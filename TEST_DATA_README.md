# Тестовые данные для Helpdesk System

## Описание

Файл `src/main/resources/test-data.sql` содержит дополнительные тестовые данные для демонстрации полной функциональности системы.

## Что включено

### Пользователи (всего 8)
- **Администратор**: admin (уже есть в data.sql)
- **Операторы**: operator1, operator2, operator3
- **Пользователи**: user1, user2, user3, user4, user5

**Пароль для всех**: `password`

### Заявки (10 штук)
- Различные статусы: Новая, В работе, Решена, Закрыта
- Различные приоритеты: Низкий, Средний, Высокий, Критический
- Различные категории: ПО, Оборудование, Сеть, Доступы
- Некоторые назначены операторам, некоторые нет

### Комментарии
- Множество комментариев к заявкам
- Диалоги между пользователями и операторами

### История изменений
- Полная история изменений статусов
- История назначений операторов
- История изменения приоритетов

## Как загрузить тестовые данные

### Вариант 1: Через psql
```bash
# Подключитесь к базе данных
psql -U helpdesk_user -d helpdesk_db

# Выполните скрипт
\i src/main/resources/test-data.sql
```

### Вариант 2: Через командную строку
```bash
psql -U helpdesk_user -d helpdesk_db -f src/main/resources/test-data.sql
```

### Вариант 3: Через DBeaver или другой GUI клиент
1. Откройте файл `src/main/resources/test-data.sql`
2. Скопируйте содержимое
3. Выполните SQL в вашем клиенте

## Особенности

- Все INSERT запросы используют `ON CONFLICT DO NOTHING` или проверки `WHERE NOT EXISTS`
- Данные можно загружать многократно без дублирования
- Используются временные метки относительно текущего времени (NOW() - INTERVAL)
