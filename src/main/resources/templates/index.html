GET /api/tickets - Получить все заявки

POST /api/tickets - Создать заявку

GET /api/tickets/{id} - Получить заявку по ID

PUT /api/tickets/{id}/status - Изменить статус

PUT /api/tickets/{id}/assign - Назначить оператора

GET /api/reports/pdf - Скачать PDF отчёт
