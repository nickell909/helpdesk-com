СВЯЗИ И ИХ КАРДИНАЛЬНОСТЬ:

1. Пользователь ──N:1── имеет роль ──────────────── Роль
2. Заявка ────────N:1── создана пользователем ──── Пользователь
3. Заявка ────────N:1── назначена на ───────────── Пользователь (оператор)
4. Заявка ────────N:1── имеет категорию ────────── Категория
5. Заявка ────────N:1── имеет приоритет ────────── Приоритет
6. Заявка ────────N:1── находится в статусе ───── Статус
7. Комментарий ───N:1── принадлежит заявке ────── Заявка
8. Комментарий ───N:1── написан пользователем ─── Пользователь
9. История ───────N:1── относится к заявке ────── Заявка
10. История ──────N:1── изменена пользователем ── Пользователь

ДЕТАЛИ СУЩНОСТЕЙ:

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ ПОЛЬЗОВАТЕЛЬ (User)                                                                 │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: user_id (BIGINT)                                                  │
│ Атрибуты:                                                                           │
│   - login (VARCHAR(50), UNIQUE)                                                     │
│   - password_hash (VARCHAR(255))                                                    │
│   - full_name (VARCHAR(100))                                                        │
│   - email (VARCHAR(100), UNIQUE)                                                    │
│ Связи:                                                                              │
│   - имеет роль → Роль (N:1, обязательное)                                           │
│   - создает заявки ← Заявка (1:N)                                                   │
│   - назначены заявки ← Заявка (1:N, необязательное)                                 │
│   - пишет комментарии ← Комментарий (1:N)                                           │
│   - вносит изменения ← История (1:N)                                                │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ РОЛЬ (Role)                                                                         │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: role_id (BIGINT)                                                  │
│ Атрибуты:                                                                           │
│   - name (VARCHAR(50), UNIQUE)                                                      │
│ Значения: USER, OPERATOR, ADMIN                                                     │
│ Связи:                                                                              │
│   - назначена пользователям ← Пользователь (1:N)                                    │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ ЗАЯВКА (Ticket)                                                                     │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: ticket_id (BIGINT)                                                │
│ Атрибуты:                                                                           │
│   - ticket_number (VARCHAR(20), UNIQUE) — формат TKT-YYYY-NNNN                      │
│   - title (VARCHAR(200))                                                            │
│   - description (TEXT)                                                              │
│   - created_at (TIMESTAMP)                                                          │
│   - updated_at (TIMESTAMP)                                                          │
│ Связи:                                                                              │
│   - создана пользователем → Пользователь (N:1, обязательное)                        │
│   - назначена на → Пользователь (N:1, необязательное)                               │
│   - имеет категорию → Категория (N:1, обязательное)                                 │
│   - имеет приоритет → Приоритет (N:1, обязательное)                                 │
│   - находится в статусе → Статус (N:1, обязательное)                                │
│   - имеет комментарии ← Комментарий (1:N)                                           │
│   - имеет историю ← История (1:N)                                                   │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ КАТЕГОРИЯ (Category)                                                                │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: category_id (BIGINT)                                              │
│ Атрибуты:                                                                           │
│   - name (VARCHAR(100), UNIQUE)                                                     │
│ Значения: Программное обеспечение, Оборудование, Сеть, Доступы, Прочее             │
│ Связи:                                                                              │
│   - используется в заявках ← Заявка (1:N)                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ ПРИОРИТЕТ (Priority)                                                                │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: priority_id (BIGINT)                                              │
│ Атрибуты:                                                                           │
│   - name (VARCHAR(50), UNIQUE)                                                      │
│ Значения: Низкий, Средний, Высокий, Критический                                     │
│ Связи:                                                                              │
│   - используется в заявках ← Заявка (1:N)                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ СТАТУС (Status)                                                                     │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: status_id (BIGINT)                                                │
│ Атрибуты:                                                                           │
│   - name (VARCHAR(50), UNIQUE)                                                      │
│ Значения: Новая, В работе, Решена, Закрыта                                          │
│ Связи:                                                                              │
│   - используется в заявках ← Заявка (1:N)                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ КОММЕНТАРИЙ (Comment)                                                               │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: comment_id (BIGINT)                                               │
│ Атрибуты:                                                                           │
│   - content (TEXT)                                                                  │
│   - created_at (TIMESTAMP)                                                          │
│ Связи:                                                                              │
│   - принадлежит заявке → Заявка (N:1, обязательное)                                 │
│   - написан пользователем → Пользователь (N:1, обязательное)                        │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────┐
│ ИСТОРИЯ ЗАЯВКИ (TicketHistory)                                                      │
├─────────────────────────────────────────────────────────────────────────────────────┤
│ Ключевой атрибут: history_id (BIGINT)                                               │
│ Атрибуты:                                                                           │
│   - field_name (VARCHAR(100)) — название измененного поля                           │
│   - old_value (VARCHAR(500)) — старое значение                                      │
│   - new_value (VARCHAR(500)) — новое значение                                       │
│   - changed_at (TIMESTAMP) — дата и время изменения                                 │
│ Связи:                                                                              │
│   - относится к заявке → Заявка (N:1, обязательное)                                 │
│   - изменена пользователем → Пользователь (N:1, обязательное)                       │
└─────────────────────────────────────────────────────────────────────────────────────┘
